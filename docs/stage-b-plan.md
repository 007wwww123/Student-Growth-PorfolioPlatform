## 三、实施顺序（每项独立分支 + PR）

### B-1 临时授权完整化（F-17 / AC-053）

- 新表 `sys_approval`（临时授权、敏感导出、更正共用）。
- 申请（1–4 小时、理由）→ 另一管理员审批 → 生效；到期自动失效；申请人/审批人可撤销。
- JWT 过滤器按数据库有效期计算 `tempGrant`，审批通过无需重新登录；到期后即使旧令牌未过期也不再放行。
- 审计：申请/通过/拒绝/撤销/到期/越权。
- 前端 `/admin/temp-grants`。

### B-2 变更记录与申诉（F-18 / AC-070）

- `arc_change_log` 查询接口：学生本人、COU 本班、ADMIN 授权；字段级前后值脱敏。
- 学生对某条变更发起申诉（`sys_approval` 类型 `APPEAL`），COU 处理；申诉状态展示。
- 前端档案时间线/变更记录页。

### B-3 班级汇总 Excel + 敏感列审批（F-13 / AC-044）

- COU 本班导出，按字段配置列；默认脱敏，敏感列需 `EXPORT_SENSITIVE` 审批单。
- 复用 `sys_approval`；导出任务落 `sys_export_task`（类型 CLASS_EXCEL）；水印与下载审计。
- 前端班级台账「导出 Excel」入口。

### B-4 数据字典维护（F-15 / AC-008）

- `sys_dict` / `sys_dict_item`；类型：民族、证书类型、事件级别、兴趣标签、谈话主题。
- 停用选项：新填报不可选，历史值显示「摄影（已停用）」；字段选项与字典的映射可配置。
- 前端 `/admin/dicts`。

### B-5 站内通知 + 自动保存（AC-012）

- `sys_notification`：提交/退回/通过/归档/申诉结果；列表、未读数、已读。
- 前端 35 秒自动保存草稿，提示「已保存 HH:mm」。

### B-6 附件 + 归档解冻 + MENTOR 更正

- MinIO/本地文件存储、上传/下载、类型/大小校验、下载审计；`basic.photo` 与证书证据打通。
- 归档解冻审批（`sys_approval` 类型 `UNFREEZE`），解冻后回 APPROVED 并留痕。
- LOCKED 后 MENTOR 追加更正记录（不覆盖原文），COU 审批。

### B-7 F-16 统计补强（可选，视进度）

- 补退回率、平均审核时长、按板块退回分布；不改现有 dashboard 口径。

## 四、验证门槛（每个 PR 必须满足）

1. 后端 `mvn -B test` 全绿；新增服务/权限/状态机必须有单测。
2. 前端 `type-check` + `check:nav` + `smoke:mock` + `build` 全绿。
3. 真库冒烟脚本覆盖：正常路径、越权、状态冲突、到期/撤销。
4. 干净重建 01→N 后 e2e 8/8/8/11 无回归。
5. 审计/敏感字段/导出水印不降级。
